# StatusWatch 🔎

Monitor de sites e APIs desenvolvido em Python.

O StatusWatch verifica uma URL, identifica o status da resposta HTTP e mede o tempo de resposta do servidor.

## ✨ Funcionalidades

- 🌐 Monitoramento de URLs
- 📡 Verificação de status HTTP
- ⏱️ Medição do tempo de resposta
- 🔄 Múltiplas verificações
- 📋 Histórico das verificações
- 🛡️ Tratamento de erros e timeout

## 🛠️ Tecnologias

- Python
- Requests

## 📁 Estrutura

StatusWatch/
├── app/
│   ├── __init__.py
│   ├── main.py
│   └── monitor.py
├── requirements.txt
└── README.md

## 🚀 Como executar

Instale as dependências:

    pip install -r requirements.txt

Execute o projeto:

    python -m app.main

Depois, informe a URL que deseja monitorar.
